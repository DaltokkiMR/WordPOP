# WordPOP

교재와 과를 고른 뒤 플래시카드, 영영풀이 O/X, AI 영영풀이 5지선다 시험, AI 영영풀이 O/X 시험으로 공부하는 로컬 앱입니다. AI 시험은 ChatGPT로 로그인한 로컬 Codex, GitHub 계정으로 연결한 Copilot, Claude 구독으로 로그인한 로컬 Claude Code를 사용하며, 세 서비스를 동시에 연결해 단계마다 다른 서비스의 모델을 쓸 수 있습니다. 플래시카드와 기존 O/X는 AI 연결 없이 사용할 수 있습니다.

## 실행

Node.js 22.12 이상을 설치한 컴퓨터에서 터미널을 열고 실행합니다. 이 프로젝트에서는 Node.js 24로 확인했습니다.

```sh
cd /Users/daltokki/Developer/WordPOP
npm install
npm start
```

브라우저에서 **http://127.0.0.1:3000**을 엽니다. 터미널을 켜 둔 동안 사용할 수 있으며 `Ctrl+C`로 종료합니다. 주소가 이미 사용 중이면 `PORT=3001 npm start`로 실행하고 표시되는 주소를 여세요. 저장된 학습을 이어가려면 같은 브라우저와 주소를 사용하세요.

### 더블클릭으로 실행 (macOS)

```sh
npm run app
```

프로젝트 폴더에 `WordPOP.app`이 만들어집니다. 더블클릭하면 서버를 켜고 기본 브라우저로 앱을 엽니다. 실행 중에는 Dock에 아이콘이 남으며, 아이콘을 다시 누르면 브라우저 창을 다시 열고, Dock에서 **종료**하면 서버도 함께 꺼집니다. Dock에 고정하거나 `/Applications`로 옮겨도 됩니다.

- 앱에는 프로젝트 폴더 경로가 기록되므로, 폴더를 옮기면 `npm run app`을 다시 실행합니다.
- 터미널에서 이미 `npm start`로 켠 서버가 있으면 브라우저만 열고 서버는 건드리지 않습니다.
- 3000번 포트를 다른 프로그램이 쓰고 있으면 다른 주소로 바꾸지 않고 안내만 합니다. 브라우저 저장 학습이 이 주소에 연결되어 있기 때문입니다.
- 서버 로그는 `~/Library/Logs/WordPOP/server.log`에 남습니다.

## 사용 방법

1. 사이드바의 교재 폴더를 열고 체크박스로 원하는 과를 선택합니다. 단어 범위는 여기서만 선택하며, 본문에서는 학습 방법과 옵션을 정합니다. 여러 과와 여러 교재를 동시에 선택할 수 있습니다. 같은 영단어가 여러 과에 있으면 한 번만 학습하되 뜻은 합칩니다.
2. **플래시카드**에서는 카드 범위, 한 구간의 단어 수와 순서 섞기를 정합니다. 카드 범위는 AI 시험과 같은 슬라이더에서 **전체**, **복습 필요 이상**, **모름 이상**, **우선 학습** 중에서 고르며, 선택한 과 안에서 그 단계 이상인 카드만 덱으로 만듭니다(예: **모름 이상** = 모름 + 우선 학습). 일부 뜻만 ‘이 뜻 모름’으로 표시한 카드는 슬라이더에 보이는 단계(최소 **복습 필요**)에 따라 들어갑니다. 단계마다 카드 수가 표시되고, 해당 카드가 없으면 시작할 수 없습니다. 예전에 고른 카드 범위는 그 단계 이상으로 이어지며, **모름·복습 필요**는 **복습 필요 이상**이 됩니다. 카드는 처음에 초록색 막으로 덮여 단어만 보입니다. 막을 누르거나 `Space`를 누르면 막이 아래로 내려가며 모든 한글 뜻·영영풀이 쌍과 내 노트가 드러나고, 막은 카드 아래쪽에 **아직 모르겠어요** 띠로 남습니다. 카드 오른쪽 바깥의 **알고 있어요 →** 또는 `Enter`는 아는 단어, **아직 모르겠어요** 띠 또는 `Space`는 모르는 단어로 표시합니다. 모르는 단어만 같은 구간에서 반복합니다. 모두 알면 `Enter`로 다음 구간에 갑니다. 마지막 구간은 남은 단어 수만큼 진행합니다.
3. **영영풀이 O/X**에서는 플래시카드와 같은 **출제 범위** 슬라이더(범위는 따로 기억합니다)와 문항 수를 정하고 **시험 만들기**를 누릅니다. 만든 시험은 사이드바의 **학습물 보기** 버튼을 누르면 카드로 모아 볼 수 있습니다. 카드는 종류별 색으로 구분되고 위의 분류 버튼과 **진행 중만** 버튼으로 걸러 볼 수 있으며, 카드의 휴지통 버튼을 누르고 확인하면 문항과 풀이 결과를 함께 삭제합니다. 삭제는 되돌릴 수 없습니다. 영단어와 풀이가 맞으면 `O`, 다르면 `X`를 누릅니다. 채점·올바른 뜻을 확인한 뒤 `Enter`로 다음 문제에 갑니다. 같은 시험에서 동일한 단어는 중복되지 않습니다. 설정한 문항 수가 범위 안 단어 수보다 크면 범위 안 단어 수만 출제합니다.
4. 시험 결과에서 문항별 풀이를 펼치거나 틀린 단어만 플래시카드로 복습합니다.

모든 조작은 버튼으로도 가능합니다. 과 선택, 플래시카드 진행, 기존 O/X 시험과 뜻별 출제 횟수는 브라우저 저장 공간에 자동 저장됩니다. 만든 시험은 각각 진행 상황과 완료 결과를 보관하므로 목록에서 다시 열 수 있습니다. 새 시험이나 새 플래시카드를 만들어도 기존 시험과 중단한 플래시카드는 유지됩니다.

플래시카드도 시험처럼 시작할 때마다 **학습물 보기**에 하나씩 추가되며, 여러 개를 동시에 진행할 수 있습니다. 각 플래시카드는 제목(예: ‘플래시카드 (모름 이상) · 25과, 26과’)과 암기한 단어 수·현재 구간을 보여 주고, 누르면 그 플래시카드의 진행 위치에서 이어갑니다. 새 플래시카드나 틀린 단어 복습을 시작해도 기존 진행은 그대로 남습니다. 휴지통 버튼으로 진행 중인 플래시카드를 하나씩 삭제할 수 있습니다. 끝까지 마친 플래시카드는 목록에서 빠지며, 결과는 아래의 암기 기록 파일에 저장됩니다. 이전 버전에서 이어가던 플래시카드 하나는 첫 플래시카드로 자동으로 옮겨집니다.

플래시카드 아래의 슬라이더로 단어의 학습 필요성을 **우선 학습**(빨강) · **모름**(주황) · **복습 필요**(초록) · **끔**(회색) 중 하나로 정합니다. 단축키는 차례로 `Q`·`W`·`E`·`R`이며, 슬라이더를 누르거나 좌우로 끌면 가까운 단계로 미끄러지듯 옮겨 가고, 슬라이더에 초점이 있으면 화살표 키로도 옮길 수 있습니다. 두 단계를 함께 고를 수는 없습니다. 뜻을 펼친 뒤 각 뜻의 **이 뜻 모름**을 누르거나 뜻 번호 키(`1`, `2`, `3`…)로 모르는 의미만 여러 개 선택할 수도 있습니다. 슬라이더가 **끔**이 아닌 단어에서 뜻을 하나도 고르지 않으면 모든 뜻을 모르는 것으로 봅니다. 모든 뜻을 골라도 마찬가지입니다. 그래서 뜻이 하나뿐인 단어에는 **이 뜻 모름**이 없습니다. 모르는 뜻을 하나라도 고르면 **끔**이던 단어는 **복습 필요**로 올라가고, 이미 **복습 필요** 이상이면 단계는 그대로 둡니다. 모르는 뜻을 모두 해제해도 단계는 내려가지 않으며, **끔**을 고르면 선택한 모르는 뜻도 함께 지웁니다. 이전 버전에서 **모름**과 **복습 필요**를 함께 표시한 단어는 **모름**으로 이어받습니다. 표시 버튼을 클릭한 뒤에도 `Space`·`Enter`는 버튼 대신 아직 모름·알고 있음으로 동작합니다. 표시를 바꿔도 카드가 넘어가지는 않습니다. 뜻을 펼치면 카드 아래쪽 노트 칸에 헷갈리는 점이나 외우는 방법을 적을 수 있고, 입력칸을 벗어나면(`Esc` 포함) 저장됩니다. 노트는 AI 시험을 만들 때 참고합니다. 표시와 노트는 원래 단어 JSON에 저장되며, 저장 중 빠르게 바꾼 선택도 보존됩니다. 기존 **약간 모름** 기록은 **복습 필요**로 이어받습니다. 완료하면 ‘아직 모르겠어요’를 누른 횟수를 단어별로 기록합니다. 처음부터 알면 0회이며, 이전 버전에서 수집하지 않은 횟수는 기록 없음으로 남깁니다. 완료 기록은 `records/flashcard/<책>/unit-<과>.json`에 최신 결과로 저장하고, 일부 단어만 복습하면 나머지 기록은 유지합니다. 저장 실패 시 재시도할 수 있습니다.

## AI 영영풀이 시험

1. 앱의 **AI 설정**을 열면 **ChatGPT**, **GitHub Copilot**, **Claude**의 연결 상태가 함께 나타납니다. 필요한 서비스에 각각 로그인해 두면 세 연결이 동시에 유지됩니다. ChatGPT는 별도로 설치한 Codex CLI 로그인을 사용합니다. Copilot은 앱과 함께 설치된 공식 GitHub 도구를 사용하며, **GitHub로 로그인**을 누른 뒤 표시된 코드를 GitHub 로그인 창에서 승인합니다. 해당 계정의 Copilot 이용 권한이 필요합니다. Claude는 별도로 설치한 Claude Code CLI의 Claude 구독(Pro·Max 등) 로그인을 사용하며, **Claude로 로그인**을 누르면 열리는 브라우저 창에서 승인합니다. 터미널에서 `claude auth login`으로 미리 로그인해 두어도 됩니다. Claude 모델 목록은 설치된 Claude Code가 알려 주는 대로 표시되므로, 최신 모델(예: Claude Opus 5.5)이 보이지 않으면 터미널에서 `claude update`를 실행한 뒤 **연결 확인**을 누릅니다. API 키로 별도 연결하는 경로는 사용하지 않습니다.
2. **단계별 모델**에서 자료 수집·단어 선별·문제 생성·독립 검수마다 AI 연결과 모델을 고른 뒤 설정을 저장합니다. 예를 들어 문제 생성은 Claude, 독립 검수는 ChatGPT처럼 섞어 쓸 수 있습니다. 한 단계의 서비스를 바꿨다가 되돌리면 그 서비스에서 고른 모델이 다시 선택됩니다. 연결되지 않은 서비스로는 저장할 수 없습니다. 설정을 바꿔도 이미 생성 중인 시험은 처음 설정을 유지하고, 변경은 새 시험부터 적용됩니다.
3. 과를 선택하고 **AI 영영풀이 시험**을 고릅니다. **출제 범위**는 슬라이더에서 **전체**, **복습 필요 이상**, **모름 이상**, **우선 학습** 중에서 고릅니다. ‘이상’은 더 강한 단계도 함께 담는다는 뜻이며(예: **모름 이상** = 모름 + 우선 학습), 단계마다 해당 단어 수가 표시됩니다. **모르는 의미만**을 켜면 모르는 뜻으로 보는 뜻만 출제합니다. 뜻이 여럿인 단어는 ‘이 뜻 모름’으로 고른 뜻(고른 뜻이 없으면 모든 뜻)이 대상이고, 뜻이 하나인 단어는 **모름** 이상일 때만 들어갑니다. 끄면 범위 안 모든 단어의 모든 뜻을 고르게 출제합니다. 범위·모르는 의미만·문항 수·난이도는 AI O/X와 따로 기억하며, 예전에 고른 **모름·복습 필요** 범위는 **복습 필요 이상**으로 이어집니다. 문항 수는 범위 안 단어 수(중복 제거)의 5분의 1 이하이므로, 범위에 단어가 5개 이상 있어야 시작할 수 있습니다. **헷갈리는 단어 위주** 토글을 끄면 과별로 고르게, 켜면 단어 전체 표시·모르는 뜻 선택·내 노트·암기 횟수·이전 시험 기록을 참고해 출제합니다. 예전에 저장한 ‘헷갈리는 단어’ 모드 설정은 토글이 켜진 상태로 이어집니다. 노트는 두 모드 모두에서 문제와 오답 보기를 만들 때 참고합니다. 헷갈리는 단어 위주는 어떤 단어를 먼저 고를지만 정하고, 어떤 뜻을 출제할지는 **모르는 의미만**이 정합니다. 헷갈리는 단어 위주로 출제할 때에는 **우선 학습**, **모름**, **복습 필요** 순으로 먼저 고릅니다. 아직 저장하지 못한 표시나 노트가 있으면 저장을 마친 후 출제합니다.
4. 난이도는 슬라이더에서 고르며, 쉬운/보통/어려운 문항의 구성 비율을 정합니다. 쉬움은 70/20/10%, 보통은 25/50/25%, 어려움은 10/30/60%입니다. 단어장에 수록된 뜻 안에서 출제합니다.
5. ‘옳은 것’과 ‘옳지 않은 것’을 섞은 5지선다 시험을 생성하고 별도 AI 요청으로 검수합니다. 모든 답을 선택해 제출하면 점수·문항별 난이도·정답·해설을 확인합니다. 답은 제출 전에 바꾸거나 중단 후 이어서 풀 수 있습니다.

### AI 영영풀이 O/X

**AI 영영풀이 O / X**는 단어 하나와 AI가 쓴 영영풀이 하나를 보여 주고, 그 풀이가 단어의 실제 뜻이면 `O`, 아니면 `X`를 고르는 시험입니다. 5지선다와 같은 네 단계(자료 수집·단어 선별·문제 생성·독립 검수)와 같은 AI 설정을 사용합니다.

- **출제 범위** 슬라이더, **모르는 의미만**, 난이도 슬라이더는 5지선다와 같습니다. 해당 단어가 없으면 시작할 수 없으며, 플래시카드·5지선다와 설정은 따로 기억합니다.
- 한 문항에 한 단어를 쓰므로 문항 수는 출제 범위의 단어 수까지 정할 수 있습니다. O와 X는 가능한 한 절반씩 무작위 순서로 나옵니다. 난이도 비율은 5지선다와 같습니다.
- **헷갈리는 단어 위주**를 켜면 **우선 학습**, **모름** 단어와 ‘이 뜻 모름’으로 표시한 뜻을 먼저 고릅니다. **모르는 의미만**을 함께 켜면 모르는 뜻에서만 출제합니다. 내 노트에 ‘~와 의미 혼동’처럼 헷갈리는 점을 적었다면, X 문항은 혼동한 단어·뜻의 풀이를 제시하고 O 문항은 둘을 가르는 핵심을 담은 풀이를 제시해, 헷갈리던 부분을 정확히 구분하는지 확인합니다. 결과 화면과 Markdown에는 문항마다 **확인한 혼동**과 구분 해설이 표시됩니다. 표시·노트·기록이 전혀 없으면 일반 출제로 바뀝니다.
- X 풀이는 그 단어의 어떤 실제 뜻으로도 맞지 않아야 하며, 독립 검수는 정답·노트를 보지 않고 판정합니다. 단어장의 정답 풀이를 X로 쓰면 앱이 거절합니다.
- `O`·`X` 키 또는 버튼으로 답하고, 답한 뒤 `Enter`나 `→`로 다음 문항, `←`로 이전 문항에 갑니다. 제출 전에는 답을 바꿀 수 있습니다. 결과 파일은 5지선다와 같은 `records/ai-test/`에 저장되며, 다음 AI 출제는 두 형식의 기록을 모두 참고합니다.

AI 시험은 서버 파일에 저장되어 브라우저 저장 공간과 별도로 유지됩니다. `records/ai-test/YYYY-MM-DD-NNN.json`에 교재·과, 실제 출제 단어·뜻, 단계별 AI 연결 서비스(`providers`)와 모델, 문제와 응답을 보관합니다. 완료하면 같은 이름의 `.md`에 결과와 AI 약점 요약을 저장합니다. 화면에서도 범위를 확인하고 두 파일을 내려받을 수 있습니다. 다음 출제에는 서비스와 관계없이 관련 완료 시험의 JSON과 Markdown을 함께 사용합니다. AI 요약에 실패하더라도 채점 결과는 저장되며 요약만 다시 요청할 수 있습니다. 요약과 요약 재시도는 해당 시험의 자료 수집 단계에 저장된 서비스와 모델을 사용합니다. **학습물 보기**에서 AI 시험을 삭제하면 JSON과 Markdown을 모두 지우고 진행 중인 요약도 중단하며, 이후 출제에서 그 기록을 참고하지 않습니다.

각 단계는 고른 서비스의 사용량으로 처리됩니다. ChatGPT는 해당 계정의 Codex 한도, Copilot은 GitHub Copilot 이용량, Claude는 해당 Claude 구독의 사용 한도를 씁니다. 시험에 쓰는 서비스는 모두 연결되어 있어야 하며, 하나라도 연결이 끊기면 시험을 만들지 않습니다. 실패한 검수에 따른 수정 요청도 사용량에 포함될 수 있습니다. 연결 실패나 사용할 수 없는 모델을 다른 서비스·모델로 임의 대체하지 않습니다. 내부 구조와 검수 기준은 [AI 파이프라인 안내](docs/ai-pipeline.md)에 정리했습니다.

다의어는 실제로 표시된 횟수가 적은 뜻을 우선 선택하고, 횟수가 같으면 무작위로 선택합니다. 따라서 같은 단어를 반복해서 시험 보면 여러 뜻을 골고루 만날 수 있습니다. X문항은 뜻마다 작성된 `wrongEn`을 사용하며 다른 단어의 풀이를 임의로 가져오지 않습니다. 기본 Wordmaster는 O와 X가 가능한 한 절반씩 출제됩니다. 추가 자료에 `wrongEn`이 없으면 해당 뜻은 O문항으로만 나옵니다.

## 포함된 자료

- 원문: `material/wordmaster_25_30_46_50.md` (변경 없이 보존)
- 결과: `word_list/wordmaster/unit-25.json` 등 11개 파일
- 범위: 25~30과, 46~50과 / 과별 40단어 / 총 440단어·726개 뜻쌍
- 원문에 없던 영영풀이와 X용 풀이를 LLM으로 작성했습니다. 원문 뜻은 `sourceMeaning`에 보존하고, 명백한 오타와 특이 용법은 `sourceNote`에 기록했습니다. 자동 검사와 별도로 의미를 읽어 교차 검토했습니다. 출판사의 공식 영영풀이가 아닙니다.

## 새 자료 추가

원문을 `material/`에 보관하고, [변환용 프롬프트](docs/convert-prompt.md)와 [JSON 형식 안내](docs/word-format.md)에 맞춰 `word_list/책이름/과별파일.json`을 만드세요. 앱의 **자료 새로고침**을 누르면 바로 표시됩니다. 잘못된 파일은 다른 자료의 사용을 막지 않고 파일별 경고로 표시됩니다.

원문은 LLM으로 변환하여 JSON으로 준비했고, 앱은 준비된 JSON을 읽습니다. 앱 안에서 원문을 업로드해 단어장으로 변환하는 기능은 포함하지 않습니다.
